QSV2G notebook research output. Metrics are simulator/software measurements, not deployed V2G results.
Use manifest.json to identify algorithms, platform, protocol version and known limitations.
qss_ideal_reconstruction.csv verifies 3 pairs x 3 ternary values; qss_x_noise_recovery.csv is a specified X-error model.
qsv2g_failure_tests.csv contains expected and actual rejection/acceptance checks.
qsv2g_end_to_end_timing.csv and qsv2g_phase_timing.csv measure local wall-clock implementation costs.
Do not make security superiority or real-quantum hardware claims based on these plots.

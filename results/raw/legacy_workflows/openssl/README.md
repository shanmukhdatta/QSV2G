# Full-protocol simulation — OpenSSL backend

The CSVs and manifest are extracted from the corresponding **unchanged** ZIP in [`../archives/`](../archives/). They cover QSS correctness, baseline workflows, rejection/failure cases, phase timing, resource accounting and AES-GCM packet sizes. See `manifest.json` for the **reported** runtime environment and hashes. The plots appear in [`../../figures/experimental/`](../../figures/experimental/).

**Caution:** execution times from this dataset must not be averaged with the other backend as if they were controlled replicates from a common environment. Performance is software-prototype behavior, not hardware quantum-network latency.

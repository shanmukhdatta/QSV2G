# Available run logs

The available plain-text execution logs are extracted from the outputs of three **locally executed** notebook snapshots. These are presented under [`local_executed/`](local_executed/).

The reference output ZIP archives contain **structured logs** in the form of CSV files, manifests, and an execution trace, in `../results/`. Original full Kaggle cell logs and Kaggle run IDs were not supplied; this repository does not claim to contain them.

# Software environment

The result manifests describe the **reported** Python and cryptographic backend versions for their respective runs. Source notebooks include setup cells that install optional dependencies when required. Reproduction may depend on CPU platform, available OpenSSL version, local package wheels and backend availability.

A convenience dependency list is included, but it is **not an exact lockfile for the original runs**. Do not cite cross-machine execution timings as controlled benchmark results without a fixed environment.

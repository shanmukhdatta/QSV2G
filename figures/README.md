# Figures / experiment plots

The folder [`experimental/`](experimental/) contains PNGs extracted *without re-rendering or editing* from the original result archives. Backend and variant names identify the reported source archive.

These are **experimental plots only**; publication architecture/sequence diagrams from the unpublished paper are deliberately not included here. Nothing in this repository represents newly measured hardware results.

- [Stage 03 original noise figures](experimental/stage03/original/) and [separate corrected figure and analysis montage](experimental/stage03/review_corrected/).
- [Stage 04 original performance figures](experimental/stage04/original/).

Original plots are unchanged copies of result ZIP members. The corrected Stage 03 figure is explicitly an analyst-generated visual, not the original plotted artifact.

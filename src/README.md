# Reference implementation

`qsv2g_core.py` is extracted **without modifying the implementation body** from cell 4 of the main protocol notebook. Its SHA-256 is recorded in `../docs/PROVENANCE.md`. This module represents a research simulator, using an ideal qutrit statevector for quantum sharing. It does not implement physical quantum channels, a hardware charger, malicious-secure verifiable QSS, or a deployed authentication server.

The full notebooks drive demonstrations and tests; this source file is provided to support inspection and reuse.
